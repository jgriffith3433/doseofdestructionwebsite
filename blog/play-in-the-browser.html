Play it in the browser

September 22, 2026

There is nothing to install. Play, in the menu on every page, opens the game in this site. The first visit downloads the build, so the bar at the start can sit there for a bit. Later visits can reuse the copy kept in the browser.

If a build has not been published yet, the game page says so instead of loading a match. When a build is up, that same page loads it. The privacy policy says what the download keeps on your device.

If a load fails, refresh once. If it still will not start, write through the contact page and say which browser you are using.
